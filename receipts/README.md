# Receipt scope

These receipts were issued during the matching campaign before the repeated generated prelude was
replaced by the audited shared `src/main/n64dk_lift.h`. The function bodies and compiler output did
not change, but the source-file hashes did, so the old receipts are retained only as historical
evidence and are not used for current tracker credit.

Current credit is validated from the normalized source hashes in `provenance/main/` and the clean
fixed-address replay in `evidence/link/`, which rebuilt 805/805 functions and the complete main
image with zero differing bytes. New receipts should be issued from the normalized sources when a
future receipt refresh is performed.
